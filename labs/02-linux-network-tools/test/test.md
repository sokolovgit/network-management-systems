# Тест до ЛР2 (Studease)

5 питань, 3 хвилини. Платформа показує 0/5: викладач попереджав, що так і має бути.
Питання 1, 4, 5 спираються на формулювання з методички (розділ «Що таке nc / nmap / sysctl»).

## 1. Які можливості NetCat (nc) прямо наведені в матеріалі? (кілька варіантів)

- **A. Читання та запис через UDP-з'єднання.** ✔
- **B. Сканування портів.** ✔
- **C. Прослуховування портів.** ✔
- **D. Читання та запис через TCP-з'єднання.** ✔
- **E. Передача файлів.** ✔

Відповідь: **A, B, C, D, E**. Методичка: «використовується для читання та запису в
мережеві підключення за допомогою TCP або UDP. Він має деякі чудові функції, зокрема
сканування портів, передачу файлів і прослуховування портів».

## 2. Яку інформацію може надати netstat? (кілька варіантів)

- **A. Мережеві підключення.** ✔
- **B. Статистику інтерфейсів.** ✔
- **C. Інформацію про програми, що прослуховують порти.** ✔
- **D. Таблиці маршрутизації.** ✔
- E. Вміст MIB SNMP.

Відповідь: **A, B, C, D**. Методичка описує netstat як утиліту для мережевих підключень,
таблиць маршрутизації й статистики інтерфейсів, а також для перевірки, які програми
прослуховують які порти. MIB читають `snmpwalk`/`snmpget`.

## 3. Яке твердження найточніше описує iptables?

- **A. Це утиліта для налаштування, підтримки та перевірки правил фільтрації IP-пакетів у Netfilter.** ✔
- B. Це утиліта для редагування DNS-зон.
- C. Це аналізатор лише SCTP-пакетів.
- D. Це програма для створення SSH-ключів.
- E. Це система зберігання MIB.

Відповідь: **A**. Netfilter – брандмауер ядра Linux, iptables ним керує.

## 4. Для яких задач використовується Nmap? (кілька варіантів)

- **A. Сканування портів.** ✔
- **B. Виявлення хостів і служб.** ✔
- **C. Інвентаризація мережі.** ✔
- **D. Виявлення операційної системи.** ✔
- **E. Визначення версій служб.** ✔

Відповідь: **A, B, C, D, E**. Методичка: «Для виявлення хостів і служб … Функції Nmap
включають сканування портів, визначення MAC-адрес, визначення версії, виявлення ОС,
інвентаризацію мережі, відображення мережі тощо».

## 5. Які твердження правильно описують sysctl у матеріалі? (кілька варіантів)

- **A. У назвах sysctl косі риски шляху замінюються крапками.** ✔
- B. sysctl працює виключно з Ethernet-драйверами.
- **C. sysctl читає та дозволяє задавати поточні параметри ядра.** ✔
- **D. Параметри пов'язані з віртуальною файловою системою /proc/sys.** ✔
- E. sysctl призначений лише для сканування портів.

Відповідь: **A, C, D**. `/proc/sys/net/ipv4/ip_forward` ↔ `net.ipv4.ip_forward`;
`sysctl -w net.ipv4.icmp_echo_ignore_all=1` змінює параметр на льоту. Сканують порти
nmap і nc.
