# Тест до ЛР6 (Studease)

5 питань, 3 хвилини. Платформа показує 0/5: викладач попереджав, що так і має бути.
Питання 1, 3, 4, 5 – з теоретичної частини методички, 2 – зі скриптів лаби.

## 1. Що таке Netmiko?

- A. Реляційна база даних мережевих станів.
- B. Протокол транспортного рівня.
- C. Система моніторингу тільки через SNMP.
- **D. Python-бібліотека для автоматизації керування мережевими пристроями через SSH або Telnet.** ✔
- E. Графічний редактор конфігурацій.

Відповідь: **D**. Методичка: «бібліотека для мови програмування Python, призначена для
автоматизації управління мережевими пристроями через SSH (Secure Shell) або Telnet».

## 2. Які параметри з'єднання можуть бути присутні у словнику device_conf? (кілька варіантів)

- **A. `password`** ✔
- **B. `port`** ✔
- **C. `host`** ✔
- **D. `device_type`** ✔
- **E. `username`** ✔

Відповідь: **A, B, C, D, E**. У `mgmt.py` / `configure_eth1.py`: `device_type: 'linux'`,
`host: '10.10.0.2'`, `username: 'root'`, `password: '12345'`, `port: 22` (плюс
`session_log`, `auth_timeout`).

## 3. Чому парсинг текстового виводу команд корисний у сценаріях Netmiko?

- A. Він потрібен лише для зміни пароля.
- **B. Він дозволяє перетворювати відповіді пристроїв на дані, зручніші для автоматизованої обробки та аналізу.** ✔
- C. Він використовується для створення MIB.
- D. Він автоматично створює OpenFlow-контролер.
- E. Він замінює SSH фізичним кабелем.

Відповідь: **B**. Перевага «Форматування виводу» з методички: Netmiko допомагає аналізувати
вивід, що полегшує обробку. У лабі – `ipparse.py`, який розбирає `ip a` на інтерфейси,
стан і адреси.

## 4. Які типи пристроїв згадуються як об'єкти керування Netmiko? (кілька варіантів)

- **A. Комутатори.** ✔
- B. Лише веббраузери.
- C. Тільки DNS-зони без мережевого пристрою.
- **D. Файрволи.** ✔
- **E. Маршрутизатори.** ✔

Відповідь: **A, D, E**. Методичка: «різними типами мережевих пристроїв, такими як
маршрутизатори, комутатори, файрволи тощо».

## 5. Коли Netmiko особливо корисний у керуванні мережею?

- A. Коли мережевий пристрій не має жодного інтерфейсу віддаленого доступу.
- B. Коли потрібно замінити IP протоколом SNMP.
- **C. Коли потрібно програмно повторювати команди, збирати результати та змінювати конфігурацію на віддалених пристроях.** ✔
- D. Коли потрібно лише редагувати локальний HTML-файл.
- E. Коли потрібно тільки намалювати схему мережі без взаємодії з пристроями.

Відповідь: **C**. Методичка: автоматизація рутинних завдань – виконання команд, зчитування
конфігурацій, встановлення параметрів. A хибне: Netmiko потребує SSH/Telnet.
